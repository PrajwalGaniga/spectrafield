# spectrafield

Interactive Forensic Field Testing & Cryptographic Chain-of-Custody Simulation.

## Features
- **Skeuomorphic & Neumorphic Tactile UI**: Designed with authentic extruded bevels, recessed wells, amber/green LED indicators, and physical tactile depth.
- **Story Director**: Step-by-step guided mission walkthrough covering field interdiction, optical calibration, colorimetry, sealing, and courtroom verification.
- **Three.js 3D Molecular Reaction Chamber**: Interactive 3D glass test ampoule with real-time fluid transformation and effervescent bubbling particles.
- **Tactical Handheld Mobile Terminal**: Realistic ruggedized forensic phone interface with optical reticle and live reaction telemetry.
- **Tamper-Evident Evidence QR Tag**: High-resolution QR code generator for evidence packaging with 5-point zero-trust courtroom parity checks.
- **Interactive Tamper Attack Stress Test**: Live demonstration of broken cryptographic parity upon unauthorized data modification.
